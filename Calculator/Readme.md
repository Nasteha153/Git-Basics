# Modern Interactive Calculator

A modern and responsive calculator built with **HTML**, **CSS**, and **JavaScript**. The application provides a clean user interface, keyboard support, light and dark themes, and a calculation history panel for an improved user experience.

---

## Features

- Basic arithmetic operations
  - Addition (+)
  - Subtraction (-)
  - Multiplication (×)
  - Division (÷)
- Responsive design
- Dark and Light theme toggle
- Keyboard input support
- Calculation history
- Clear (C) button
- Delete (DEL) button
- Formatted number display
- Division by zero protection

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## Keyboard Shortcuts

| Key | Action |
|------|--------|
| 0–9 | Enter numbers |
| + | Addition |
| - | Subtraction |
| * | Multiplication |
| / | Division |
| Enter | Calculate result |
| Backspace | Delete last digit |
| Escape | Clear calculator |
