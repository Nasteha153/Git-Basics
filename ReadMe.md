Git Practice Exercise
Overview

This Exercise is intended for learning only. It helps develop practical experience with Git by repeating the same workflow many times and understanding how version control works.

The main goal of this exercise is to repeat the Git workflow until it becomes a natural habit.

Objectives
- Make 100 Git commits.
- Practice the complete Git workflow.
- Learn how to track file changes.
- Use different file types in a single project.
- Git Commands Practiced
